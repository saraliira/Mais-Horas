+Horas — Gerenciador de Horas Acadêmicas

1. Descrição do Projeto

O +Horas é uma aplicação web desenvolvida para auxiliar estudantes do ensino superior no gerenciamento e acompanhamento das horas obrigatórias de Extensão e Atividades Extracurriculares. O sistema busca solucionar dificuldades relacionadas ao controle das horas acadêmicas, à visualização do progresso por período ou bloco e à organização de certificados e comprovantes. A aplicação permitirá cadastrar atividades, acompanhar metas, calcular automaticamente as horas cumpridas e pendentes e armazenar comprovantes digitais, facilitando a organização acadêmica e contribuindo para uma experiência mais acessível e inclusiva.

3. Eixo Tecnológico Escolhido

Eixo 3 — Tendências Emergentes e Novos Padrões da Web

O projeto explorará padrões modernos de desenvolvimento web, com foco na criação de componentes reutilizáveis ou no processamento de tarefas utilizando Web Workers. 

A Prova de Conceito (PoC) demonstrará o funcionamento real do recurso escolhido, integrado à interface da aplicação.

Requisito universal: Acessibilidade e UX Inclusiva

A aplicação utilizará HTML semântico, navegação por teclado, componentes acessíveis, atributos ARIA e uma interface responsiva, buscando facilitar o uso por estudantes com diferentes necessidades de acessibilidade.

4. Tecnologias Utilizadas
Frontend / Interface: React.js com HTML5 Semântico 
Bootstrap
Biblioteca de acessibilidade: Radix UI ou Headless UI (fornecem componentes desacoplados com navegação de teclado e atributos ARIA nativos).
Backend / APIs (se aplicável): Node.js (Express ou NestJS) para API RESTful.
Supabase ou Firebase (autenticação, banco de dados PostgreSQL e serviço de Storage para os arquivos PDF/Imagens dos certificados).
Plataforma de Hospedagem / Deploy: Vercel ou Netlify (Frontend).


Observação: a stack definitiva dependerá das tecnologias efetivamente implementadas pela equipe.

5. Funcionalidades Previstas
Cadastro e configuração do perfil acadêmico.
Definição de metas de horas por período ou bloco.
Registro de atividades de Extensão e Extracurriculares.
Cálculo automático de horas cumpridas, pendentes e percentuais de conclusão.
Histórico de atividades cadastradas.
Upload, visualização e download de certificados.
Interface acessível e responsiva.

6. Requisitos para Execução Local
Pré-requisitos
Node.js instalado.
npm instalado.
Git instalado.
Clonar o repositório

Substitua URL_DO_REPOSITORIO pelo endereço real do repositório público.

Entrar na pasta do projeto
cd nome-da-pasta

Instalar as dependências
npm install

Executar a aplicação

Após iniciar o servidor de desenvolvimento, acesse no navegador o endereço local informado no terminal, geralmente http://localhost:5173 em projetos React com Vite.
